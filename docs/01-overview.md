# ۰۱ — نمای کلی

## پروژه چیست؟

وب‌سایت و پنل مدیریت **آکادمی مربیگری و بدنسازی ناظری (Fit by Nazeri)**؛ پلتفرم فارسی (RTL) برای:

- معرفی مربی و برند، وبلاگ تخصصی، نظرات و قهرمانان (شاگردان)
- فروش آنلاین «برنامه تمرینی»، «برنامه غذایی» و «پکیج ترکیبی» همراه با پرسشنامه‌ی ورودی
- پنل داخلی برای مربی و سوپروایزر جهت مدیریت محتوا، سفارش‌ها و ساخت برنامه برای هر شاگرد
- پنل شاگرد برای دیدن برنامه تمرینی/غذایی تحویل‌شده

شعار برند: «رشد تو مسیر ما». دامنه: `fitbynazeri.com`. سرور: `37.32.4.38`.

## امکانات

| بخش | توضیح |
| :--- | :--- |
| صفحه اصلی | Hero اسلایدی، درباره، قهرمانان، نظرات، بخش وبلاگ، فرم مشاوره، ماشین‌حساب BMI (همگی از CMS قابل ویرایش‌اند) |
| وبلاگ | مقاله با دسته‌بندی، ویرایشگر Tiptap، پنل SEO، FAQ، نظرات با تأیید و پاسخ مربی |
| قهرمانان | پروفایل عمومی شاگرد (`/students/[slug]`) با وزن، مدال و مسیر پیشرفت |
| دریافت برنامه | انتخاب پکیج، ثبت‌نام/ورود، پرسشنامه‌ی ورودی (`/get-plan/intake`)، ثبت سفارش |
| داشبورد | منوی متفاوت برای superadmin، admin و student ([07-frontend.md](07-frontend.md)) |
| رسانه | آپلود با بهینه‌سازی خودکار تصویر (حداکثر عرض 1920، JPEG کیفیت 82) و SEO تصویر |
| پکیج‌ها | سوپروایزر پکیج، قیمت و ویژگی‌ها را مدیریت می‌کند |

## پشته‌ی فنی

| لایه | فناوری |
| :--- | :--- |
| فرانت‌اند | Next.js 16.3.4 (App Router)، React 19، TypeScript، Tailwind CSS 4، framer-motion، swiper، lucide-react، Tiptap 3 |
| بک‌اند | Go 1.25، Fiber v2، GORM، SQLite (`mattn/go-sqlite3`، نیاز به CGO)، `golang-jwt/jwt/v5`، bcrypt، `disintegration/imaging` |
| دیتابیس | فایل SQLite: `backend/nazeri_fitness.db` (go.mod به pgx هم اشاره دارد ولی استفاده نشده) |
| اجرا روی سرور | pm2 (`nazeri-api`، `nazeri-web`) پشت nginx، Ubuntu |
| زبان محتوا | فارسی، راست‌به‌چپ |

## وضعیت

پروژه در حال استفاده است و کد از روی سرور production گرفته شده. دیتابیس و آپلودها عمداً داخل گیت نیستند (داده‌ی کاربران).
